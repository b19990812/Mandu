# 自有图片样本

服务在内存中按需生成 PNG，不复制网站漫画，不依赖 Pillow。

| 路由 | 尺寸 | 用途 |
|---|---|---|
| `/images/page-1.png`、`page-2.png` | 320×480 | 普通页、分页和 Range |
| `/images/long-1080.png` | 1080×30000 | 第一档长图解码风险 |
| `/images/long-2160.png` | 2160×60000 | 第二档长图解码风险 |

颜色条与十进制行号是程序生成的几何图形，声明为 CC0-1.0。PNG 由逐行压缩生成；生成器不会分配整幅原始图像。长图的设备内存和可读性仍须由 T06b 实测。JPEG、WebP、多种 EXIF 方向与真实站点长图待 T06a/T06b 补充，不因现有 PNG 样本而算完成。
