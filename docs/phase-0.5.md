# 0.5.0 功能覆盖增量

日期：2026-10-26，Asia/Hong_Kong。基线0.4.0；用户授权按照Mihon功能对照逐项补齐，之后要求完成下一步并制作handoff。本次收口M01–M10的当前实现及M16隐身部分，未声称所有差距完成。API26目标/编译、min24、phone/tablet保持；数据库向前迁移至schema6。

## 实现

- 每章独立位置、已读/未读、书签；隐藏历史保留位置。schema5保留原最近进度并建立chapter_progress，schema6增加下载队列顺序。未来数据库版本拒绝写入。
- 目录标题搜索和已读/未读/书签/离线筛选，批量已读/未读；书架标题/作者搜索、更新/标题/未读/最近阅读排序、离线/未读筛选、多选分类及移除收藏。
- 同阅读器换章、可跳过已读、临近章末准备最多一章和一张起读图；仅Wi-Fi预取可选。位置保存失败时保留当前章。试读不自动跳入正式目录，条漫通过章末按钮进入下一章。
- 每本漫画独立模式、方向、背景、缩放方式和触区配置，可恢复全局。五种模式：横向单页、纵向单页、无缝条漫、间隔连续、双页。背景深/灰/浅；单页/双页自动/适宽/适高；左右区/三等分/仅菜单及点击反转。条漫始终适宽，左右点击滚动约0.8屏。1×优先翻页，缩放后优先平移；纵向长图需先滚到底再划动换图。
- 全局搜索最多两个源并发；来源分页和错误独立，旧查询结果不能覆盖新查询。
- 自定义`.hsmbackup`手动备份/预览/原子合并恢复：书架、目录、分类、逐章进度及安全阅读设置。16MiB/100000行上限，固定列数组、稳定身份/类型/摘要/外键校验，分类同名映射，新旧位置/已读/书签按独立时间戳合并。图片、规则、下载指针、Cookie/令牌不进入备份；不兼容Mihon备份格式。摘要用于完整性，不提供来源认证。
- 本地CBZ/ZIP或多张JPEG/PNG/WebP导入，生成完整离线章节并加入书架，复用统一阅读器。自然页序，书名/章名稳定身份，同章重新导入保留进度，成功后替换旧文件，失败清理新文件；阅读中的文件禁止覆盖。32MiB/图、512MiB/章、最多2000图；界面一次最多选择200个文件。ZIP只支持未加密Stored/Raw Deflate及UTF-8/ASCII文件名，拒绝越界、符号链接、重叠、重复和损坏内容，逐图限额输出并核对CRC。
- 下载排队上下移，顺序独立于下载进度更新时间；运行任务不允许重排。完整离线章可导出Stored CBZ，逐图读入并校验SHA，导出过程中持有文件引用；取消/损坏时清空不完整输出，可能留下空文件。导出同样有32MiB/图、512MiB归档预算（预留目录开销）。
- 隐身阅读不写正式或试读位置和历史；主动书签、下载及阅读设置仍保存。开关从下次打开章节生效。全应用主题尚未实现。
