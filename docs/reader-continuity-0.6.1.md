# 0.6.1 阅读提示、动画与自动续章

日期：2026-10-26（Asia/Hong_Kong）。版本0.6.1/code9；API26/min24、schema6不变。用户自行真机确认，本轮没有设备操作或安装。

## 原因与修复

1. **移除正常等待的覆盖文字。** RetainedCanvas原有“正在准备下一页，当前页面保留”来自双页/纵向路径；HorizontalPager也有相邻页准备提示。本轮移除这些正常加载文字，准备时安静保留旧图；真实加载失败的原因与重试按钮保留。
2. **补齐实际缺失的动画路径。** 0.6.0仅HorizontalPager的水平/点击单页使用动画，RetainedCanvas只有画面交接，因此双页/纵向模式看不到滑动并非只是时长短。本轮RetainedCanvas在新首屏就绪后同时平移旧图和新图，双页横向滑入、纵向单页纵向滑入，280ms EaseInOut；HorizontalPager点击滑动由220ms改为280ms，拖动剩余路程按比例收尾，最短160ms。方向由ReaderVM记录请求页相对当前页及阅读方向，不改变菜单逻辑上一页/下一页含义。不是纸张卷曲特效。
3. **自动续章。** 水平手势在最后一页继续有效拖动时进入下一章，反方向第一页可进入上一章；不再只做边界回弹。条漫/间隔连续模式在用户主动滚动到底后触发续章，不要求点击按钮；布局恢复、后台重建和缩放不会独自触发连跳。显式关闭autoNext时仍保留手动入口。
4. **连续缓存及会话交接。** 临近末尾至少10张时（短章则更早）准备最多一章清单及前三张图片；第二/三张失败不丢弃已准备的第一张。前进续章从第0张起读。changeChapter在旧章仍显示期间取用准备会话、取得起读图片并尝试预算内预解码，保存旧章失败/新章失败均保持旧会话。成功后才转移cache所有权与章信息，避免先清空total/asset再开章。HorizontalPager保留旧章当前节点，直到新章首屏就绪再释放；条漫使用readerEpoch隔离新旧图块身份，避免同ordinal复用旧章图片。
5. **取消与范围。** 换章期间忽略新的跳页请求，后台/退出取消换章及预取；遵守现有自动续章、预取、仅Wi-Fi、离线与跳过已读设置，试读不跳正式目录。没有整章PixelMap预解码或无限缓存。条漫是带缓存的自动章切换，不是无限追加全部章节的超长列表；网络未准备好仍需等待，但无需强制按钮操作。

## 关键文件

- `ui/RetainedCanvas.ets`：移除等待覆盖层文字；新旧画面平移及动画结束资源释放。
- `ui/HorizontalPager.ets`、`reader/PagerWindow.ets`：静默等待、统一动画时长、章边界手势、旧章节点保留。
- `ui/WebtoonViewer.ets`：滚动到底自动续章、恢复/缩放隔离、新章图块key。
- `vm/ReaderVM.ets`：目标章准备完毕后交接、失败保留当前章、输入/取消隔离。
- `reader/ChapterAhead.ets`：前三张有界预取与非首张失败降级。
- `pages/ReaderPage.ets`、`ui/SpreadViewer.ets`：向真实显示路径传递动画方向。

## 人工确认

覆盖安装最终0.6.1包，不卸载、不清数据。

1. 《绍宋》双页模式点击下一组/上一组，观察两列各自有280ms横向滑动，无正常等待文字；再检查纵向单页向上/下切换及水平单页左右点击。
2. 将阅读方向改为从右到左，核对翻页运动方向；快速重复点击，确认没有旧动画回调误删当前图片。
3. 自动续章开启时，到章末继续水平拖动或点击下一页；条漫直接滚到底，无需下一章按钮。下一章应从第一张开始，当前章历史保留。
4. 网络慢或失败时，应保留当前页，真实错误可从菜单/重试入口处理；恢复网络后再次继续。检查后台返回、退出重开，进度与章节对应正确。
5. 自动续章关闭、试读、离线仅有部分章节时，确认不越过对应限制。最终页无下一章时保持边界反馈。
