# 0.8.0 阅读器翻页更新

日期：2026-10-27（Asia/Hong_Kong）

## 交互和排版

- 左右翻页区在轻点抬手后直接触发翻页，取消用于双击识别的固定 400 毫秒等待；中部保留单击菜单、双击缩放，双指缩放继续可用。条漫的侧边点击滚动同样立即触发。
- 水平滑动、单页卷页和双页仿真均由拖动位移直接控制。停住不自动前进，反向拖动会回卷；松手依据距离和速度完成或回弹。动画尚未结束时，可以重新按住接手拖动。
- 双页使用同一个有界页面窗口，每组两页准备好后才提交页码。仿真纸张以书脊为轴弯曲，正面采样当前翻动页，背面采样下一组的对应页，另一半显示未翻动页与新露出的页；RTL 镜像处理。
- 左页图像向右靠书脊，右页图像向左靠书脊。中缝为 4 vp，外侧留白基准为视口宽度的 2.5%，限制在每侧 12–40 vp。图像保持原比例，留白区域仍在可点击画布内。原图自身的白边保留。
- 最后一组仅剩一张图像时居中显示，通过单页卷页进入或返回，不补造第二张图片。

## 实现边界

`PagerWindow` 负责稳定身份、当前/前后共最多三组以及文件引用；单页每组一页、双页每组两页。`ReadingCanvas` 负责图像布局和缩放；`HorizontalPager` 统一处理手势和提交；`BookCurlCanvas` 只绘制纸张。没有修改数据表或源适配器。

`CurlFrameStore` 在画面准备好后预先获取有界纹理，拖动读取现成纹理，不逐次截取组件。单张纹理限制 2 MiB，总缓存限制 8 MiB；页面离开、尺寸/方向/模式/适配变化时废弃旧结果并释放纹理。长图滚动改变纹理键，滚动停止后更新画面，避免卷页时闪回旧位置。

目标页未完成下载或解码时，当前页继续保留并给出准备状态与轻微阻尼反馈；准备完成后，正在进行的拖动会按最新手指位移更新。网络等待仍取决于源和缓存状态。
