# 后台图像传输决定

2026-10-26。影响R08、T07、G4。生产已采用受控流写，最终设备后台验收待完成。

## 真机选型依据

自有127.0.0.1:8765服务和API24平板实际调用request.agent：普通图片与正常Range可下载，禁止跳转配置阻止302跟随。但服务端声称Content-Range为0-1023/1024并发送4096字节时，设置ends=1023的任务仍完成且写4096字节；分块响应结果相同。

Range参数不能作为不可信响应的硬上限。系统代理原型未接入发布版本，已移入temp；数据库预留列保留以维持升级兼容，生产不创建代理任务。证据：temp/stage3/native-agent-boundary-result.json、自有服务日志及故障路由。

## 当前实现

- 受控RCP实际接收字节限额，每图最大32MiB；写.part后验证容器、系统解码、尺寸和SHA256，再提交文件。
- 仅在用户请求的实际图片传输期间申请Background Tasks Kit的dataTransfer任务；声明KEEP_BACKGROUND_RUNNING，通知回到下载管理。
- 租约按活动传输计数，最后一项结束释放；暂停、取消和失败均在finally释放资源。系统拒绝申请则明确提示保持前台，前台下载继续可用。
- 后台不提交下一张图片，当前图片尽力完成，其余队列等待前台。进程结束后按已验证页面恢复，未提交.part不计入完成。
- 清单持久化稳定页标识，不保存临时签名图片网址；恢复通过固定源快照重取。源禁用或网址/版本变化不静默换版本。

华为官方[受控文件下载示例](https://developer.huawei.com/consumer/cn/doc/doccenter-industry-solutions/filedownloadcontrol-0000002720681848)包含受控网络和dataTransfer组合。本项目据此选择实现路线，具体设备授权、后台保持及市场要求仍需验证。
