## 模块边界

页面 → VM → AppContainer → 业务服务/仓库。SourceRegistry为规则及内置适配器提供统一SourceHandle、固定版本、变更保护和受控Transport。页面不解析网页，数据库不依赖源解析代码。

ReadingCanvas/WebtoonViewer负责布局和手势，ReaderVM管理会话/位置/资源，TileDecoder管理解码队列及像素租约。浏览缓存、离线文件和规则快照独立。网址变化使旧请求失效，不改写漫画身份和历史。

下载以持久化状态为准，取消等待在途操作释放。系统代理的Range上限真机发现反例，因此未接入生产；当前采用受控RCP流写和有限dataTransfer租约，见[技术决定](background-transfer-decision.md)。
