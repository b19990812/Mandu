# 全局搜索：0.9.7

搜索已统一为查询所有已激活且支持搜索的漫画源，并按漫画源分组返回。0.9.7 / versionCode 25 已保留数据安装到平板。

## 使用方式

书架顶部、浏览页顶部、各源首页的“全局搜索”均进入同一页面。从单个源首页进入时，查询范围仍是全部已激活源。

1. 输入关键词，点击“搜索全部来源”或使用键盘搜索键。
2. 提交后收起键盘，各源结果陆续出现；分组标题显示源名称、当前数量和搜索状态。
3. 每组先显示 3 部；“查看全部/收起结果”仅切换已取得结果的显示范围。
4. 有后续分页的源提供独立“加载更多”；失败的源提供“重试此源”。这些操作只处理对应源。
5. 可取消当前搜索并保留已取得结果；未完成的分组提供“继续搜索”。修改关键词会取消旧查询并清除旧结果，重新提交后查询新关键词。

每次新搜索重新读取激活列表，过滤停用、移除、没有活动快照或不支持搜索的源。同名漫画在不同源下分别展示，保留各自详情入口；排序和匹配规则使用各源原始返回。

## 实现边界

- `business/GlobalCatalogSearch.ets`：负责两路并发、每源独立游标与状态、增量结果、单源加载/重试、分页去重和取消代次。单源请求期限为 30 秒，总期限按源数量分配；总结果继续限制在 5000 项。
- `vm/SearchVM.ets`：读取最新可搜索源列表、聚合状态与分组展示行；源名称与界面文案在此映射。保留平铺 `data` 供既有跨源迁移页面使用。
- `pages/SearchPage.ets`：展示全局分组结果，提供提交、取消、展开/收起、按源分页和重试。
- `ui/LibraryPanel.ets`、`ui/BrowsePanel.ets`、`pages/SourceHomePage.ets`：统一全局搜索入口。书架标题/作者输入框继续承担本地书架筛选。
- `AppScope/app.json5`：版本更新为 0.9.7 / code 25。

本次没有调整数据库结构、源协议、阅读器或请求调度器。0.9.6 HIP 修复涉及的适配器和图片校验源码摘要均保持一致。
