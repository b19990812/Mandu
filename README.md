# 漫读 · HS Mihon

以 [Mihon](https://github.com/mihonapp/mihon) 的书架、详情及沉浸阅读交互为参考的原生 HarmonyOS 漫画阅读应用。当前 **0.9.5（versionCode 23）**，ArkTS / ArkUI / Stage / 单 entry 模块。API 26 编译及目标，最低 HarmonyOS 6.1.1（API 24），支持手机和平板。

截至 2026-10-28，用户已确认基础功能可供日常使用，本版作为 GitHub 私有仓库的首个保存基线。0.9.5 恢复按显示宽度解码，将前台静态解码缓存提高至 128 MiB，并保留独立 16 MiB 预解码池。版本细节和此前的定向构建、安装证据见 [0.9.5 说明](docs/curl-quality-budget-0.9.5.md)。这次仓库归档未重跑功能测试；尚未完成的验收项目仍按各专题记录保留。

0.8.6 将阅读历史按漫画汇总，每部只显示最近章节和位置，移除200条显示截断；隐藏整部漫画的历史入口，保留逐章进度、已读及书签。图片预缓存默认和选项上限提高至20张，单双页均按图片数量预取。见[历史与20张预缓存说明](docs/history-prefetch-0.8.6.md)。

源适配开发候选已到 **0.9.3**：新增漫蛙当前网站 API、完整目录、图片分页及流式解码；新增 JoyACG 漫画搜索、列表、整本目录与图片清单；Vomic 增加更新、题材分类和完结栏目。15 组协议检查、7 组生产下载链路合成检查和 Release 签名构建通过；真实正文图片和设备阅读尚未验证。启用方式、候选包与证据见 [多漫画源接入说明](docs/multi-sources-0.9.3.md)。此前 COPY 独立 API 与网页模式保留，见 [COPY API 接入说明](docs/copy-api-integration-2026-10-28.md)；0.9.1 的 Vomic、HIP 等进展见[源适配进展](docs/source-adaptation-2026-10-28.md)。

0.8.5 修复漫画源首页未打包路由导致点击无响应；阅读器改用XComponent/OpenGL ES原生曲面网格，实现单双页页角卷曲、正反面纹理与动态光影。修复旧页面回调覆盖新实例、Release原生接口被混淆及双页翻动下半幅白块。真实双页正向/反向中间帧与区域对比通过，稳定60FPS和手机尺寸完整矩阵仍待验。见[曲面翻页实现与证据](docs/page-curl-0.8.5.md)。

0.8.4 增加包子和 COPY 原生漫画源首页：推荐、热门、更新、新上架、完结和分类，COPY 另有排行榜。按源网站提供题材、地区、状态、排序和榜单筛选，支持组合条件及可用栏目的分页；封面网格随窗口宽度调整。复用详情、收藏和阅读流程，保留网站首页入口。真实页面快照解析、16项定向检查和签名构建通过；本版新首页尚未真机验收。详见[源首页说明](docs/source-home-0.8.4.md)。

0.8.3 根据授权真机诊断修复双页绑定、进度保存和原生位图复制导致的翻页退出，并隔离渲染中的状态改写。连接上限从10秒调整到30秒，已观察到约15.7秒握手后成功返回，保留VPN、总截止时间和证书验证。星海单/双页、换章、冷启动恢复及包子一个6图章节的前后翻页有真机证据；仍有个别TLS超时，不能标记全部真实源恢复。详见[真机诊断](docs/device-image-0.8.3.md)。

0.8.2 增加图片加载到界面的显式状态同步，允许读取完整章节时打开菜单，并新增网站首页入口；修正会话读取异常时请求名额未释放的问题。原始并发上限的加入时间及验证边界见 [加载恢复说明](docs/reader-recovery-0.8.2.md)。

0.8.1 移除图片下载和请求调度中的两层固定 500 毫秒等待，保留并发和服务器冷却处理。复现测量及真实网络验收边界见 [网络等待修正](docs/network-pacing-0.8.1.md)。

0.8.0 增加即时点击翻页、跟手滑动/卷页与双页仿真，并收窄双页中缝、把留白移到两侧。交互说明与本轮验证边界见 [阅读器翻页更新](docs/reader-turn-0.8.0.md)。

## 当前功能

- 书架、更新、历史、浏览、更多五个主入口；封面网格、搜索/排序/筛选、多对多分类和批量分类/移除收藏；单源或全局搜索，各源独立分页。
- 详情、完整目录、标题搜索、已读/未读/书签/离线筛选，批量已读/未读/下载、收藏和继续阅读；手动检查书架更新。
- 章节点击进入独立全屏阅读器；1×时左右翻页区轻点立即触发，按阅读方向和点击反转设置决定前后；中间轻点菜单、双击缩放，也支持双指缩放。水平/卷页/双页仿真支持跟手、回拖和松手回弹；双页向书脊靠齐，外侧留白。普通页适屏，长图适宽分块；放大后优先平移。
- 默认提前缓存后20张、回看前1张；可设置2/4/6/10/20张。跨图保留重叠预取请求，当前图请求优先于预取和下载。缓存有字节预算，不把全章图片解码到内存。
- 五种模式：横向/纵向单页、无缝/间隔连续、双页；背景、适配、触区和点击反转。每漫画独立配置，可恢复全局默认。正式漫画逐章保存稳定页标识/图内比例、已读和书签；隐藏历史保留位置。试读独立保存最近200个章节位置。隐身可关闭正式/试读位置与历史写入。
- 同阅读器换章、跳过已读、临近章末有界准备下一章起读图；仅Wi-Fi预取可选。条漫通过章末按钮续章。
- 下载队列、暂停 / 继续 / 取消 / 修复、启动恢复、完整及部分离线阅读；离线文件与浏览缓存分离。浏览缓存按预算清理，正在阅读的文件受引用保护。
- 排队任务上下移，完整离线章导出CBZ；本地CBZ/ZIP或多图片导入书架，复用离线阅读器。文件夹、RAR、EPUB尚未支持。
- 自定义hsmbackup手动备份、预览和合并恢复书架/目录/分类/进度/阅读设置；图片、规则和账号不在备份内，非Mihon备份格式。
- JSON / HTML 有限规则，本地文件或文本导入，预览激活、启停、手动更新、回滚、移除。不可变版本与旧请求隔离，不运行外部脚本。
- 包子 / COPY 内置适配器，支持原生首页栏目、分类筛选、搜索、详情、目录、图片清单；首页封面网格自适应手机/平板宽度，按源提供分页与筛选。各源可修改网站根地址，源身份、收藏、进度和下载不随域名改变。导入规则仍可搜索和打开网站，网页结构变化仍需修改规则或适配器。
- 阅读、缓存和 Wi-Fi 下载设置，脱敏诊断导出，应用内许可证。Debug/lab包额外包含开发实验室。

**历史验收边界（0.5.0）**：COPY原生TLS、包子历史302后403未解决；两源各三章真机整章验收仍缺。0.5.0通过32组主机定向检查、原生归档/schema6诊断和最终Release入口/阅读菜单最小核查；文件选择器实际导入/备份恢复/导出、完整手势/旋转/长时内存/下载后台矩阵未验。当时定时更新、订阅、WebView会话、迁移、Tracking和应用主题未完成。见[开发追踪](docs/mihon-parity-progress.md)。0.8.0 本轮只验证翻页相关宿主逻辑和 Release 构建，设备交互仍待集中确认。

## 使用与安装

正式包：[0.9.5 Release](artifacts/0.9.5/hs-mihon-release-default-signed.hap)；摘要见 [SHA256SUMS](artifacts/0.9.5/SHA256SUMS)。采用本机开发签名；此前已保留数据覆盖安装并确认版本、启动与进程存活。安装时保留数据，不要卸载旧版。历史版本的验证范围见对应专题记录。

```powershell
& 'D:\Software\DevEco Studio\sdk\default\openharmony\toolchains\hdc.exe' install -r .\artifacts\0.9.5\hs-mihon-release-default-signed.hap
```

浏览 → 点击包子/COPY名称 → 原生首页 → 漫画卡片 → 详情 → 章节进入阅读；首页右上角可搜索或打开网站。其他规则源点击名称进入搜索。更多中包含下载管理、设置、源规则、自定义网站和章节试读。试读的内置普通 / 长图示例明确为自有合成图，不会自动代替真实源失败。

## 本机构建

首次克隆后，复制不含签名凭据的配置模板，再通过 DevEco Studio 为本机配置自动签名：

```powershell
Copy-Item .\build-profile.example.json5 .\build-profile.json5
```

已有本机 `build-profile.json5` 时保留原文件。本机配置、密钥、证书、授权描述文件、依赖及缓存均不提交；签名由 DevEco 写入本机配置。模板默认不绑定签名，可用于构建未签名包；设备安装需要先配置签名。仓库首次保存仅包含 0.9.5 安装包，历史包保留在原本机，历史文档中的旧包相对路径可能仅在原本机存在。后续如需提交新版本安装包，应同步更新 `.gitignore` 中的版本白名单。

```powershell
.\tools\dev.ps1 -Action Info
.\tools\dev.ps1 -Action Install
.\tools\dev.ps1 -Action Build
.\tools\dev.ps1 -Action Build -Mode release
.\tools\dev.ps1 -Action Devices
```

默认使用 `D:\Software\DevEco Studio` 内的Node、JBR、Hvigor、OHPM和SDK，可用 `-DevEcoHome` 更换目录。Release使用default target并开启混淆，Debug使用lab target。脚本在产品绑定签名后要求实际执行SignHap；交付到 `artifacts/<版本>/` 并更新摘要。

临时脚本、响应、布局、截图和日志集中在 `temp/`，见 `temp/list`。`entry/build/`、`oh_modules/` 为工具输出。旧包保留；当前数据库schema6向前迁移，拒绝写入未来版本数据库，不建议降级覆盖后写入。
